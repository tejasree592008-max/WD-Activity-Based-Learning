##  Project Description

This repository contains three website projects developed as part of the Web Development Activity-Based Learning (ABL) assignment. The websites are created using HTML and CSS to practice webpage structure, styling, and design.

##  Projects Included

### 1. 🍰 Bakery and Cake Shop Website

A bakery website designed to display different varieties of cakes, pastries, and bakery products. It includes product images, names, prices, and an attractive color scheme to create a cute and aesthetic appearance.

### 2. ☕ Restaurant and Cafe Website

A restaurant and cafe website designed to present food items and menu details in an appealing layout. It focuses on organizing content, displaying images, and creating a pleasant browsing experience.

### 3. 🏔️ Adventure and Trekking Website

An adventure and trekking website designed to showcase trekking destinations and outdoor activities. It uses images, organized sections, and styling to create an engaging adventure-themed webpage.

##  Technologies Used

- **HTML5:** Used to structure the webpages and organize content.
- **CSS3:** Used to style the webpages with colors, fonts, layouts, spacing, and visual effects.

##  Learning Outcomes

Through these projects, I gained practical experience in:

- Creating webpages using HTML.
- Styling and designing webpages using CSS.
- Adding and arranging images and content.
- Working with colors, fonts, margins, and padding.
- Creating attractive layouts for different types of websites.
- Improving basic web development and design skills.

##  Conclusion

This ABL project helped me understand the fundamentals of web development through practical implementation. Creating three different websites improved my knowledge of HTML and CSS and gave me experience in designing visually appealing webpages.
